# GJ K Skin

GJ K Skin is a custom Minecraft player skin featuring a yellow hoodie with black jeans and shoes. The hoodie displays the letters "GJ" on the front and "K" on the back, creating a unique and recognizable design. This skin is perfect for players who want a stylish and recognizable appearance in the game. The skin is designed with a classic Steve body and clean pixel art, ensuring it fits seamlessly into the Minecraft universe.

## Install

1. Download the `player_skin.svg` file from the project repository.
2. Convert the SVG file to a PNG format using an image editing tool like GIMP or Inkscape.
3. Rename the PNG file to `player_skin.png`.
4. Place the `player_skin.png` file in the `assets/textures` directory of your Minecraft resource pack or directly in the `skins` folder of your Minecraft game directory.

## Use

1. Open Minecraft.
2. Go to the "Skins" tab in the main menu.
3. Click on the "Select Skin" button.
4. Navigate to the location where you saved the `player_skin.png` file.
5. Select the `player_skin.png` file and click "Open".
6. Your character will now be wearing the GJ K Skin.
